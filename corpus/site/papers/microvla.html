microVLA: minimal VLA training and inference on a 4 GB laptop GPU

KhushiJ2911 · GitHub repository 2026

project repo efbb84d8 unofficial

Cloned at the commit above. This is the repository requested for the MicroVLA row. Its README describes a 10.5M pi0.5-style model. It does not implement the 12.37M Theia + POTION checkpoint.

The cloned repository trains one small pi0.5-style policy from scratch on LIBERO-Spatial. A shared 4-layer ViT embeds two cameras, instruction words and discretized state form the prefix, and a narrower action expert predicts a 16-step chunk with flow matching. Training first matches ViT patches to frozen SigLIP features, then runs the flow-matching loss for 8,000 steps. The README reports 10.5M parameters and 270/300 successes on LIBERO-Spatial. The local 12.4M landscape note matches a different checkpoint, listed under Not the same work.

Local note: distilled vision, static text lookup, and a chunk head. This repository is a pi0.5-style ViT plus flow-matching action expert. · Embedded controller memory and latency. The README targets a 4 GB laptop GPU. · Local note: ideal baseline, about 2–3 GB VRAM. The README's small-model timing is 79 ms per chunk.

Not the same work

  • Ngseo/microvla-seqgru-libero — A different 12.37M LIBERO policy: Theia-tiny vision, a frozen POTION text table, a GRU readout, and an L1 chunk head. The RSS workshop title uses the same MicroVLA name.
  • varununayak/microvla — A 117,248-parameter RT-2 toy on a synthetic 32x32 reach task.

Model

MicroVLA is a joint prefix and action-expert transformer. Vision is a ViT of 4 layers at width 192 with 8-pixel patches, shared by both cameras plus a camera embedding. Six joint blocks run a width-256 prefix and a width-128 action expert in the same attention. The LIBERO config sets 2 cameras, state 8, action 7, and horizon 16. Class defaults in Config are the toy sizes and are not the LIBERO run.

10.5M total: vision 1.9M, prefix 5.7M, action expert 2.3M. parameter_counts() was not executed in this pass. verified

Objectives

Flow-matching loss verified

\mathcal{L}=\lVert v_\theta((1-t)a+t\epsilon,\ t\mid \text{images, instruction, state})-(\epsilon-a)\rVert^2

The code draws t from the inverse CDF of Beta(1.5, 1), scaled into (0.001, 1). The noisy action is t * noise + (1 - t) * action. The network regresses noise minus the clean action. The README writes the same path with the opposite interpolation symbol; the linked function is the one that trains.

  • a — Normalized action chunk, shape (B, 16, 7).
  • \epsilon — Gaussian noise of the same shape.
  • t — Per-sample flow time.
readme: README flow-matching display equation · MicroVLA.loss · train.py:260-266

SigLIP patch distillation verified

\mathcal{L}_{\mathrm{distill}}=(1-\cos(W v, s))+\lVert W v-s\rVert^2

For 1,000 steps only the ViT and a linear head train. One camera is chosen at random. Its image is upsampled 2x and passed through a frozen SigLIP-B/16. The loss is one minus cosine similarity plus MSE, after layer-norm on the teacher tokens.

  • v — ViT patch tokens.
  • s — Frozen SigLIP last hidden state.
  • W — Linear head from prefix width to the SigLIP width.
