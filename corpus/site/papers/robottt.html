RoboTTT: Context Scaling for Robot Policies

Yunfan Jiang, Yevgen Chebotar, Ruijie Zheng, Fengyuan Hu, Yunhao Ge, Jimmy Wu, Tianyuan Dai, Scott Reed, Li Fei-Fei, Yuke Zhu, Linxi Fan · arXiv 2607.15275 2026

PDF arXiv 2607.15275 project repo 98eb8837 unofficial

lucidrains/robo_ttt implements the fast-weight memory, TTT wrapper, sequence action forcing, and loss mask. It is not NVIDIA's GR00T N1.7 training stack. Isaac-GR00T was not cloned.

RoboTTT keeps a small MLP's weights as the policy's memory. Those fast weights are updated by gradient descent on an MSE bind of keys to values, both in training and at deployment, so an 8,000-step history does not grow a KV cache. The paper instantiates this inside each of the 16 DiT layers of GR00T N1.7. The outer loss is flow matching with an independent noise level per action chunk, and TBPTT keeps the backward pass inside a segment while the fast weights themselves continue across the segment. The clone linked below is an unofficial library of that mechanism.

Test-time training with fast weights · Short Markov memory and KV-cache growth, with an 8,000-step context in the local note · Local note: ideal stack-on, about 4–5 GB VRAM. The paper's pretraining used 16 GB200 GPUs.

Model

GR00T N1.7's Eagle VLM plus a DiT action head. A TTT layer is added after attention in each of 16 DiT layers. The fast model is a two-layer GeLU MLP. A tanh gate starts near zero so the pretrained head is preserved. The unofficial module list is the memory bind, the wrapper, and the RoboTTT trainer shell.

Original DiT 538M. Each TTT layer adds about 10M. DiT plus TTT is 690M. The Eagle VLM is extra and its parameter count was not extracted. verified

Objectives

Fast-weight update verified

W_t \leftarrow W_{t-1}-\eta\nabla_W\lVert f_{W_{t-1}}(K_t)-V_t\rVert^2,\quad O_t=f_{W_t}(Q_t)

The fast MLP is trained to map keys to values, then queried. The same step runs at train time and at deploy time. In the unofficial memory, the store function returns the negative MSE so that its gradient is the descent direction.

  • W — Fast weights of the small MLP.
  • Q,K,V — Projections of the tokens at this timestep.
  • \eta — Inner learning rate. The paper learns it on top of a base rate 0.1.
pdf: Eq. 1–2 · MemoryKeyValueBind._store · robo_ttt/robo_ttt.py:184-189

Sequence flow matching verified

\mathcal{L}_{\mathrm{fm}}(\xi;W_0)=\frac{1}{T}\sum_t\mathbb{E}_{\tau_t,\epsilon}\lVert v_\theta(\Phi_t,A_t^{\tau_t},q_t;W_{t-1})-(A_t-\epsilon)\rVert^2

Each chunk draws its own flow time tau_t = 0.999 * (1-u) with u from Beta(1.5, 1). The DiT denoises that chunk conditioned on the fast weights carried in from the previous step. A loss mask can drop timesteps so they update memory without an imitation target.

  • A_t^{\tau} — tau * A + (1-tau) * epsilon, the noised chunk.
  • W_{t-1} — Fast weights entering timestep t.
pdf: Eq. 5 · RoboTTT.forward · robo_ttt/robo_ttt.py:908-957

Tanh gate verified

O=\tanh(\alpha)\odot O_{\mathrm{TTT}}+O_{\mathrm{attn}}

Alpha is initialized near 0.001 so TTT starts as a small residual on the pretrained attention output. The unofficial wrapper uses a layer-scale initialized at 1e-4 and applies tanh.

  • \alpha — Per-channel gate, learned.

Train

1. Start from GR00T N1.7 and add a two-layer fast MLP after attention in each of 16 DiT layers. Freeze the base model during the 30k-step pretrain. verified
pdf: Appendix A
2. On each training sequence, update fast weights with the inner MSE, then apply them to the queries. verified
pdf: Eq. 1–2 · MemoryKeyValueBind._store · robo_ttt/robo_ttt.py:184-189 · TTTWrapper.forward · robo_ttt/robo_ttt.py:409-479
3. Draw an independent flow time per action chunk and average the flow-matching loss over the sequence. verified
pdf: Eq. 5 · RoboTTT.forward · robo_ttt/robo_ttt.py:908-957
4. Backpropagate only inside a TBPTT segment. Carry the fast weights across the boundary and detach their gradient there. verified
pdf: Section 3.2, TBPTT · TTTWrapper.forward · robo_ttt/robo_ttt.py:409-479
5. For video imitation or DAgger distillation, mask the flow-matching loss on context timesteps so they update memory only. verified

Gaps

  • NVIDIA has not published the GR00T N1.7 + TTT training code in the sources found here. Links are to the unofficial library, and the match is the mechanism, not a line-by-line port of the paper's trainer.
  • Eagle VLM parameter count, image resolution during pretraining, and the exact segment length used for TBPTT were not extracted.
  • The library was not imported, so there is no live parameter print.
  • No example clip aligns a training frame with a trained RoboTTT checkpoint's action and the logged action chunk.
  • The unofficial RoboTTT import failed before a forward, and the clone has no robot episode to attach a checkpoint action to.
