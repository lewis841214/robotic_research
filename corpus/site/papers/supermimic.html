SuperMimic: Scaling Humanoid Whole-Body Control with One Differentiable World Model

Qiayuan Liao, Yiyang Shao, Junfeng Long, Kevin Zakka, Roberto Horowitz, Pieter Abbeel, Koushil Sreenath · arXiv 2610.28480 2026

PDF arXiv 2610.28480 project repo 698ea39b official

Official repository at 698ea39, with mjlab_research cloned beside it. play.py exited 2 because --wandb-path is required and the README names no run. train.py ran SuperMimic-GenCoord-G1 on an RTX 5070 Ti. The W&B motion registry needs an API key, so the motion was a 64-frame random G1 clip.

One differentiable world model is fit to short windows of a MuJoCo Warp humanoid, then a tracking policy is improved by backpropagating through 32 imagined steps of that frozen model. The paper's claim is the compute cut: within 3 hours on one H100 the return passes a SONIC checkpoint that the paper accounts as 128 L40 GPUs for 168 hours. A GenCoord G1 run on an RTX 5070 Ti constructed the default MLPs and saved 18,816,634 parameters: dynamics 8,745,346, sim context 66, actor 9,839,797, critic 231,425.

Differentiable world model and short-horizon BPTT · GPU scaling of model-free RL. The paper reports more than a 1000x GPU-hour cut against the cited SONIC run. · Local note: ideal online RL, about 6–8 GB VRAM. The paper's reported runs use H100 80 GB.

Model

Dynamics is an MLP on normalized representation-state, processed action, and sim context. It predicts an acceleration-level increment that the representation integrates. The actor is a per-task encoder to a 32-d tanh latent and a shared decoder. The critic is a smaller MLP. Defaults are in SuperMimicRunnerCfg.

Objectives

World-model fit verified

\mathcal{L}_{\mathrm{WM}}(\omega)=\mathbb{E}\sum_{j=1}^{k}\big[\lVert\hat{s}_j-s_j\rVert^2+(\hat{r}_j-r_j)^2+\lVert\hat{\bar{o}}_j-\bar{o}_j\rVert^2+\mathrm{BCE}(\hat{d}_j,d_j)\big]

The official loss that was opened is the state term: squared error per named channel group, weighted by Bryson's rule 1/nominal^2, then averaged by channel count. Reward, observation, and termination heads are separate. The fit rolls the MLP forward on logged actions for k=8 and does not score the last unused action.

  • k — Autoregressive window, default 8.
  • \xi — Sim context held fixed over the window.
pdf: Eq. 1 · WorldModelLearner._compute_losses · src/supermimic/learners/wm_learner.py:169-191 · WorldModelLearner._rollout · src/supermimic/learners/wm_learner.py:145-167

Imagined return verified

\hat{J}(\theta)=\mathbb{E}\sum_{t=0}^{H-1}\gamma^t \hat{c}_t \hat{r}_{t+1}+\gamma^H \hat{c}_H V_\psi(\hat{s}_H,g_H,\xi)

The world model is frozen. The actor minimizes the negative discounted return through 32 imagined steps, plus the encoder's auxiliary latent-BC loss. Survival weight c multiplies through the predicted termination probability.

  • H — Imagination horizon, default 32.
  • V_\psi — Critic bootstrap at the end of the window.
pdf: Eq. 2 · BpttPolicyLearner._train_batch · src/supermimic/learners/policy_learner.py:99-126

Critic regression verified

\mathcal{L}_V(\psi)=\mathbb{E}\sum_t\lVert V_t-\hat{R}_t\rVert^2,\quad \hat{R}_t=\hat{r}_{t+1}+\gamma(1-\hat{d}_{t+1})\big[(1-\lambda)V_{t+1}+\lambda \hat{R}_{t+1}\big]

Targets are GAE returns on the imagined rollout, computed once and then fit for 5 epochs of 4 minibatches. The code clamps values by the maximum discounted step reward.

  • \lambda — GAE lambda, default 0.95.
